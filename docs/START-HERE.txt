[한국어]
Mac 메뉴바에서 Claude · Codex · Gemini 웹 · Antigravity의 남은 사용량을 확인합니다.
macOS 13 이상 대상. Apple Silicon / Intel 통합 앱. 화면 언어는 한국어입니다.

1. AIUsageBar.app을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 엽니다. Dock 아이콘은 없으며 화면 위쪽 메뉴바에 나타납니다.
3. 설정… → 표시 항목에서 쓰는 서비스만 켭니다.
4. Claude는 Claude Code 로그인, Codex는 이 Mac의 ~/.codex/auth.json에
   저장된 ChatGPT 로그인이 필요합니다. 웹사이트 로그인만으로는 연결되지 않습니다.
   Antigravity는 agy CLI 설치·로그인이 필요하며 기본적으로 꺼져 있습니다.
5. Gemini는 Chrome에서 로그인한 뒤 앱의 설정… → Gemini 웹 → Chrome 연결…을
   누릅니다. Chrome의 chrome://extensions/에서 개발자 모드를 켜고
   '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
   폴더 선택창에서 ⌘⇧G → 붙여넣기 → Enter 후 폴더를 선택합니다.
   확장 팝업의 '지금 갱신'으로 연결을 확인하세요. Chrome이 실행 중이어야 갱신됩니다.

모든 숫자는 남은 양입니다. G는 일반 ChatGPT 채팅이 아닌 Codex 한도입니다.
조회 실패 시 마지막 성공값과 경과 시간 또는 오류를 표시합니다.

첫 실행: 이 앱은 임시 서명만 되어 있으며 Apple Developer ID 서명·공증은 없습니다.
출처를 신뢰한다면 앱을 한 번 연 뒤 시스템 설정 → 개인정보 보호 및 보안 →
'그래도 열기'를 사용할 수 있습니다. 회사 관리 Mac은 제한될 수 있습니다.
Apple 공식 안내: https://support.apple.com/en-us/102445

업데이트: 기존 앱을 종료하고 새 버전으로 같은 위치에서 교체하세요.
Gemini 확장은 chrome://extensions/에서 새로고침하세요. 자동 업데이트는 없습니다.
앱을 옮기면 Chrome 연결을 다시 하고 새 폴더의 확장을 로드해야 합니다.

삭제: 로그인 시 자동 실행을 끄고 앱을 종료한 뒤 휴지통으로 옮기세요.
Gemini 확장과 연결 등록 파일, 필요하다면 캐시와 설정도 삭제하세요.
전체 경로와 개인정보 안내는 위의 한국어 안내에 있습니다.

[English]
See remaining Claude, Codex, Gemini web and Antigravity quota in your Mac menu bar.
Targets macOS 13+. Universal Apple Silicon / Intel app. App UI is in Korean.

1. Move AIUsageBar.app to Applications before opening it.
2. Open it and look in the top menu bar. There is no Dock icon.
3. Open 설정… (Settings) → 표시 항목 (Visible items). Enable only your services.
4. Claude requires Claude Code sign-in. Codex requires a ChatGPT login saved in
   ~/.codex/auth.json on this Mac. Website sign-in alone is insufficient.
   Antigravity requires the agy CLI and its login; it is off by default.
5. For Gemini, sign into Gemini in Chrome. In the app, click 설정… → Gemini 웹 →
   Chrome 연결… (Connect Chrome). Open chrome://extensions/ in that Chrome profile.
   Enable Developer mode, then choose Load unpacked. In the folder picker, press
   ⌘⇧G, paste, press Enter, and select the folder. Open the extension popup and
   press 지금 갱신 (Refresh now). Keep Chrome running for updates.

All percentages mean remaining. G means Codex, not general ChatGPT chat limits.
A failed request shows the last reading with its age, or an error.

First launch: ad-hoc signed; no Apple Developer ID signing or notarization.
If you trust its origin, try opening the app, then use System Settings →
Privacy & Security → Open Anyway. A managed work Mac may restrict this.
Apple's instructions: https://support.apple.com/en-us/102445

Update: quit the old app, replace it in the same location, then reopen it.
Reload the Gemini extension at chrome://extensions/. Updates are manual.
If you move the app, reconnect Chrome and load the extension from the new folder.

Uninstall: disable launch at login, quit and move the app to Trash. Remove the
Gemini extension and its registration file. Cache and preferences removal paths
and privacy details are in the English guide linked above.

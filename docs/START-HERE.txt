[한국어]
직접 설치: 아래 1–5번을 따르면 됩니다. AI나 터미널 도구 설치는 필요 없습니다.
사용량 확인은 AI 답변을 생성하지 않습니다. 메모리는 앱·Chrome·agy에서 사용됩니다.
macOS 13 이상 대상. Apple Silicon / Intel 통합 앱. 앱 UI는 한국어입니다.
메뉴바: Claude · GPT · Gemini · agy
퍼센트는 남은 양입니다. GPT는 ChatGPT 설정의 플랜 사용량을 표시합니다.
현재 Work/Codex가 공유하는 한도이며, 일반 채팅 통합은 공식 안내상 12월 예정입니다.
포함되는 기능은 ChatGPT 사용량 페이지와 README의 공식 링크에서 확인하세요.

1. AIUsageBar.app을 응용 프로그램 폴더로 옮긴 뒤 실행하세요.
2. 화면 위쪽 메뉴바에서 설정… → 표시 항목으로 필요한 서비스만 켜세요.
3. 웹만 사용한다면: Chrome에서 각 서비스에 로그인 → 앱 설정의 Chrome 연결…
   → chrome://extensions/ → 개발자 모드 → 압축해제된 확장 프로그램 로드
   → ⌘⇧G → 붙여넣기 → Enter → 폴더 선택.
   확장 팝업에서 Claude·GPT 웹 연결을 켜고 '지금 갱신'을 누르세요.
   Gemini는 자동 연결됩니다. Chrome 실행 중 10분마다 갱신됩니다. 확장에서 자동 조회를 끄면 수동 조회만 합니다.
4. 이미 로컬 도구를 쓴다면: Claude Code / Codex 로그인 정보를 사용할 수 있습니다.
   설치뿐 아니라 로그인까지 필요합니다. 터미널 창을 계속 켜 둘 필요는 없습니다.
   앱 설정에서 '로컬 로그인 — 앱 직접 조회' 또는 'Chrome 웹만'을 선택할 수 있습니다.
5. agy는 기존 CLI 설치·로그인이 필요합니다. 사용하지 않으면 숨겨 두세요.

Chrome과 로컬 앱이 서로 다른 계정일 수 있습니다. 사용할 프로필을 확인하세요.
v1.1.1에서 업데이트하면 확장을 새로고침하고 새 사이트 접근 권한을 확인하세요.

첫 실행: Apple Developer ID 서명·공증은 아직 없습니다. 출처를 신뢰한다면
실행 시도 후 시스템 설정 → 개인정보 보호 및 보안 → '그래도 열기'를 사용하세요.
Apple 공식 안내: https://support.apple.com/en-us/102445

업데이트: 기존 앱 종료 → 같은 위치에서 새 앱으로 교체 → 확장 새로고침.
앱 위치를 바꾸면 Chrome 연결을 다시 하고 새 폴더의 확장을 로드해야 합니다.
삭제: 자동 실행을 끄고 앱 종료 → 앱과 Chrome 확장 삭제. 캐시·등록 파일 경로는
README에 있습니다. 자동 업데이트 기능은 없습니다.

AI에게 위 GitHub 주소와 'README를 읽고 내 Mac에 설치하는 걸 도와줘'를
전달해도 됩니다. 로그인·보안 승인은 사용자가 직접 진행해야 할 수 있습니다.

[English]
Direct installation: follow steps 1–5; no AI assistant or terminal tool installation is required.
Usage checks do not generate AI answers. The app, Chrome and agy still use memory.
Targets macOS 13+. Universal Apple Silicon / Intel app. Korean app UI.
Menu bar: Claude · GPT · Gemini · agy
Percentages mean remaining. GPT shows the reported ChatGPT plan allowance.
Work/Codex currently share it; broader Chat integration is announced for December.
Check the usage page and official links in the README for the applicable scope.

1. Move AIUsageBar.app to Applications, then open it.
2. Use 설정… → 표시 항목 (Settings → Visible items) in the top menu bar.
3. Web-only user: sign into services in Chrome → app Settings → Chrome 연결…
   → chrome://extensions/ → Developer mode → Load unpacked → ⌘⇧G → paste
   → Enter → select the folder. In the extension popup, enable Claude/GPT
   web connections and press 지금 갱신 (Refresh now). Gemini connects automatically.
   Automatic checks run every 10 minutes while Chrome is open. Turn off automatic checks for manual-only refresh.
4. Existing local tools: use your Claude Code / Codex login. Installation alone
   is not enough; sign-in is required. A terminal window need not remain open.
   App Settings offers Local only and Chrome only connection modes.
5. agy requires its CLI and login. Hide it if you do not use it.

Chrome and local apps may use different accounts. Check the intended profile.
When upgrading from v1.1.1, reload the extension and review new site permissions.

First launch: no Apple Developer ID signing or notarization. If you trust the
source, try opening the app, then System Settings → Privacy & Security → Open Anyway.
Official guidance: https://support.apple.com/en-us/102445

Update: quit, replace the app in the same location, then reload the extension.
If moved, reconnect Chrome and load the new extension folder. Updates are manual.
Uninstall: disable launch at login, quit and remove the app and extension.
Cache and registration paths are in the README.

You can give an AI assistant the GitHub URL above and ask it to read the README
and help install the app. Sign-in and security approvals may need your input.

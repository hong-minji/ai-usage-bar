# AI Usage Bar v1.4.1

## 한국어

Chrome 창이 저절로 뜨는 현상을 제거했습니다.

- macOS에서는 마지막 Chrome 창을 닫아도 Chrome이 종료되지 않고 남아 있습니다. 이때 10분마다 실행되는 사용량 조회가 새 창을 띄우는 것이 원인이었습니다.
- 창이 열려 있을 때는 기존과 같이 현재 탭을 그대로 둔 백그라운드 탭에서 조회합니다.
- 창이 하나도 없을 때는 최소화된 창 안에서 조회한 뒤 창째로 닫습니다. 조회 중 사용자가 창을 직접 복원하면 닫지 않고 유지합니다.
- 표시 데이터와 10분 조회 주기는 그대로이고, 새 사이트 권한은 없습니다.

Chrome 확장을 새로고침하면 적용됩니다(확장 버전 1.4.1). 쓰던 앱은 그대로 두고 확장만 새로고침해도 되며, `AIUsageBar-1.4.1-universal.zip`의 앱에는 확장 1.4.1이 포함되어 있습니다.

## English

Chrome no longer opens windows on its own during usage polls.

- On macOS, Chrome keeps running after its last window closes. The 10-minute usage polls then raised a fresh window every time — this release removes that.
- With a window open, polling stays in a background tab exactly as before.
- With no window open, the poll now loads inside a minimized window and closes it afterwards. A window the user restores during a poll is kept.
- Data and the 10-minute schedule are unchanged, and there are no new site permissions.

Reload the Chrome extension to apply the fix (extension 1.4.1). Reloading the extension alone is enough; the app in `AIUsageBar-1.4.1-universal.zip` additionally bundles extension 1.4.1.

## Verification / 검증

- 200 Swift checks and 52 extension tests passed. The new tests cover windowless minimized-window polling, whole-window cleanup afterwards, and user-restored windows for both the Gemini poller and the Claude/GPT web poller.
- Universal Intel/Apple Silicon build, ZIP checksum, clean extraction and ad-hoc signature verification passed. The packaged extension includes both locale catalogs.
- Live behaviour in a windowless Chrome after reloading extension 1.4.1 is to be confirmed on the maintainer's Mac; the mocked-API tests cover the decision logic, not Chrome's own window rendering.
- Not covered by these checks: execution on Apple Silicon.

Apple Developer ID signing/notarization is not included. Not physically tested on every supported Mac or macOS 13.

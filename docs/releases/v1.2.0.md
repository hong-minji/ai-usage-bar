# AI Usage Bar v1.2.0

## 한국어

**Claude · GPT · Codex · Gemini · agy**를 별도 항목으로 표시합니다.

- Claude·Codex에 Chrome 웹 연결 추가. 터미널용 도구 설치 없이 기존 웹 로그인으로 사용량을 읽습니다.
- 기존 로컬 로그인도 유지하며 설정에서 연결 방식을 선택할 수 있습니다.
- GPT 일반 채팅은 정확한 잔여 수치를 제공받지 못해 `–`와 ChatGPT 바로가기를 제공합니다. Codex 수치를 대신 표시하지 않습니다.
- agy는 기존 CLI 연결을 유지합니다.
- 새 웹 보고서에서 이메일·사용자명·쿠키·토큰·페이지 원문을 제외합니다. Gemini의 기존 계정 확인용 이메일은 로컬에만 저장됩니다.
- 앱 패키지에는 실행에 필요한 확장 파일만 포함합니다.

**다운로드:** `AIUsageBar-1.2.0-universal.zip` (Apple Silicon + Intel, macOS 13 이상 대상).
ZIP을 풀고 앱을 응용 프로그램 폴더로 옮겨 실행하세요. 한·영 `START-HERE.txt`와 라이선스가 포함됩니다.

**업데이트:** 기존 앱을 종료하고 교체한 뒤 Chrome 확장을 새로고침하세요. 새 Claude·ChatGPT 사이트 접근 권한을 확인하고 확장 팝업에서 웹 연결을 켜세요. 앱을 옮겼다면 Chrome 연결을 다시 해야 합니다.

Apple Developer ID 서명·공증은 아직 없습니다. [첫 실행 안내](https://github.com/hong-minji/ai-usage-bar#readme)를 읽어주세요. 앱 UI는 한국어입니다.

## English

Separate **Claude · GPT · Codex · Gemini · agy** menu bar entries.

- Adds opt-in Chrome web connections for Claude/Codex without CLI installation.
- Keeps local logins and adds a connection-mode choice in Settings.
- General GPT chat shows `–` and a ChatGPT shortcut because exact remaining figures are unavailable; Codex figures are never substituted.
- agy retains its CLI connection.
- New web reports exclude emails, display names, credentials and page text. Gemini's existing account-verification email stays local.
- Release bundles include runtime extension files only.

**Download:** `AIUsageBar-1.2.0-universal.zip` (Apple Silicon + Intel, targets macOS 13+).
Extract and move the app to Applications. Includes a bilingual `START-HERE.txt` and license.

**Update:** Quit and replace the old app, reload the extension, review the new Claude/ChatGPT site permissions and enable the desired web connections. Reconnect Chrome if the app moved.

No Apple Developer ID signing or notarization yet. See the [English guide](https://github.com/hong-minji/ai-usage-bar/blob/main/README.en.md). App UI is Korean.

## Verification / 검증

- 144 Swift checks and 33 extension tests.
- Universal compilation and ad-hoc signature verification.
- Installed-app live check: local Codex, Gemini web and agy returned readings. Claude local requests returned HTTP 429; the app correctly marked cached readings stale.
- Live Chrome extension → native host → app cache verification passed for Claude, Codex and Gemini on the maintainer's Mac. Claude usage-page redirects are supported and covered by a regression test. New Claude/Codex cache files contained only the documented report fields and had owner-only permissions (0600).
- GPT intentionally shows no numerical estimate. Local Claude requests may still be rate-limited; the verified browser connection provides an alternative.
- macOS 13 and all supported hardware models have not been physically tested.

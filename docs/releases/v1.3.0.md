# AI Usage Bar v1.3.0

## 한국어

사용량 조회의 불필요한 작업을 줄이고, 터미널 없이 설치하는 방법을 먼저 안내합니다.

- Claude·GPT 연결 이름을 **로컬 로그인 — 앱 직접 조회**로 명확히 표시합니다. 기존 인증 정보로 사용량 API만 조회하며 Claude Code·Codex AI 프로세스를 실행하지 않습니다. 연결 방식과 계정은 자동 변경하지 않습니다.
- Chrome 자동 조회 간격을 5분에서 **10분**으로 늘리고, 자동 조회를 끄는 옵션을 추가했습니다. 꺼도 서비스별 **지금 갱신**으로 확인할 수 있습니다. 진행 중인 조회는 마무리됩니다.
- 메뉴를 열 때마다 추가 조회하거나 agy를 실행하지 않습니다. 예약 갱신과 명시적인 갱신은 유지합니다.
- Codex 로그를 읽는 경우 최근 5개 파일, 파일당 끝부분 최대 512 KiB만 읽습니다. 웹페이지 감시는 보고서 수신 또는 제한 시간 후 종료하고 응답 대기 중 중복 전송을 막습니다.
- 한·영 README를 **앱 다운로드로 직접 설치 / AI 도움을 받아 설치**로 나눴습니다. 모델 호출과 메모리 사용을 구분하고, 연결별 절약 방법을 안내합니다.

앱을 종료하고 `AIUsageBar-1.3.0-universal.zip`의 앱으로 교체한 뒤 Chrome 확장을 새로고침하세요. 새 사이트 권한은 없습니다. 로컬 연결을 선택했다면 확장의 같은 서비스 웹 연결도 꺼야 중복 웹 조회가 멈춥니다.

## English

Reduces unnecessary quota-checking work and puts installation without terminal tools first.

- Clarifies the **Local login — direct app query** option for Claude/GPT. It reads existing authentication and queries usage APIs without launching Claude Code or Codex AI processes. Existing account/source selections are preserved.
- Changes Chrome automatic polling from 5 to **10 minutes** and adds a manual-only option. Per-service refresh buttons remain available; an in-progress check may finish.
- Opening the menu no longer starts extra requests or agy processes. Scheduled and explicit refreshes remain available.
- Bounds Codex fallback log reads to the latest five files and at most 512 KiB from each tail. Page watchers stop after delivery or timeout and coalesce overlapping requests.
- Separates direct download installation from AI-assisted installation in both READMEs, with clear memory and model-token explanations.

Quit and replace the app, then reload the Chrome extension. No new site permissions. If you select local login, also turn off that provider's web connection in the extension to stop duplicate web checks.

## Verification / 검증

- 149 Swift checks + 41 extension tests passed, including bounded log reads, manual polling mode and content-script lifecycle checks.
- Universal Intel/Apple Silicon build, ZIP checksum, clean extraction and ad-hoc signature verification passed. Packaged app excludes test fixtures and local credentials.
- Installed-app live check on the development Mac returned Claude through its existing local login, GPT and Gemini through Chrome, and agy quota. Extension v1.3.0 was reloaded and Claude web polling was disabled in its UI.

- Memory use is not zero. Local queries avoid additional Chrome quota tabs; no fixed RAM saving or total-memory benchmark is claimed.

Apple Developer ID signing/notarization is not included. Not physically tested on every supported Mac or macOS 13. App UI is Korean.

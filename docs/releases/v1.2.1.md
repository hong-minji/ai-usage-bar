## English

Four menu entries: **Claude · GPT · Gemini · agy**.

- Removes the separate GPT chat placeholder that could not display a quota.
- Renames the existing Codex / Work plan reading to GPT. No separate chat allowance is inferred or added to it.
- Links GPT to ChatGPT plan usage and preserves existing logins, cache keys and connection preferences.
- Updates bilingual documentation to distinguish current sharing from the announced December transition.

As checked on November 14, 2026, Work/Codex currently share usage. OpenAI announces broader ChatGPT/Codex sharing for Plus, Pro and Business starting in December, excluding Instant chat. [Official notice](https://help.openai.com/en/articles/20001625-understanding-chatgpt-and-codex-usage-limits)

Download `AIUsageBar-1.2.1-universal.zip`, quit and replace the app, then reload the Chrome extension. No new site permissions compared with v1.2.0.

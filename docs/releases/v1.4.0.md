# AI Usage Bar v1.4.0

## 한국어

앱과 Chrome 확장을 영어로도 쓸 수 있습니다.

- 앱 화면이 시스템 언어를 따라 **한국어 또는 영어**로 표시됩니다. 시스템의 언어 목록에서 한국어와 영어 중 먼저 나오는 쪽을 쓰고, 둘 다 없으면 영어입니다.
- **설정… → 언어**에서 시스템 설정 따름 / 한국어 / English 중 직접 고를 수 있습니다. 바꾸면 메뉴와 설정 창이 바로 바뀝니다.
- Chrome 확장의 이름과 팝업도 Chrome 언어에 맞춰 표시됩니다. 영어 Chrome에서는 확장 이름이 **AI Usage Bar · Web Connection**입니다.
- 저장되는 한도 이름과 확장·앱 사이의 데이터 형식은 바뀌지 않았습니다. 기존 캐시와 연결 설정은 그대로 유지됩니다.
- 확장 팝업에서 Gemini 확인 시각을 수치 아래 줄에 표시합니다.
- README를 강점 중심으로 다시 정리하고 Homebrew 설치 안내를 추가했습니다.

앱을 종료하고 `AIUsageBar-1.4.0-universal.zip`의 앱으로 교체한 뒤 Chrome 확장을 새로고침하세요. 새 사이트 권한은 없습니다. 영어 macOS에서 한국어 화면을 써 왔다면 업데이트 후 영어로 보입니다. **Settings… → Language**에서 한국어를 고르면 이전과 같습니다.

## English

The app and its Chrome extension are now available in English.

- The interface follows the system language, in **Korean or English**. It uses whichever of the two comes first in your language list, and English when neither is listed.
- **Settings… → Language** lets you choose System default, 한국어 or English. The menu and the settings window switch immediately.
- The Chrome extension's name and popup follow Chrome's language. In an English Chrome the extension is named **AI Usage Bar · Web Connection**.
- Stored window labels and the data format between the extension and the app are unchanged. Existing caches and connection settings carry over.
- The extension popup shows the Gemini check time on its own line.
- Both READMEs were reorganized around what the app does well, and Homebrew installation is documented.

Quit and replace the app with the one in `AIUsageBar-1.4.0-universal.zip`, then reload the Chrome extension. No new site permissions. If you used the Korean interface on an English macOS, the app appears in English after updating; choose 한국어 under **Settings… → Language** to keep it as before.

- 200 Swift checks + 48 extension tests passed, including language selection, Korean and English display text, and key parity between the two extension catalogs.
- Universal Intel/Apple Silicon build, ZIP checksum, clean extraction and ad-hoc signature verification passed. The packaged extension includes both locale catalogs.

# AI Usage Bar v1.1.1

## 한국어

Claude · Codex · Gemini 웹 · Antigravity의 남은 사용량을 Mac 메뉴바에서 확인하세요.

**다운로드할 파일: `AIUsageBar-1.1.1-universal.zip`**

Apple Silicon과 Intel에 같은 파일을 사용합니다. macOS 13 이상을 대상으로 빌드했습니다. `Source code` 파일은 개발용이며 설치할 앱이 아닙니다.

### 설치

1. ZIP을 풀고 `AIUsageBar.app`을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 열고 화면 위쪽 메뉴바에서 **설정… → 표시 항목**을 선택합니다.
3. 쓰는 서비스만 켜고 [한국어 연결 안내](https://github.com/hong-minji/ai-usage-bar#readme)를 따릅니다. ZIP 안의 `START-HERE.txt`에서도 설치 순서를 볼 수 있습니다.

**첫 실행 안내:** Apple Developer ID 서명·공증은 아직 없습니다. 출처를 신뢰하는 경우 한 번 실행을 시도한 후 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 이용할 수 있습니다. [Apple 공식 안내](https://support.apple.com/en-us/102445)를 확인하세요.

Swift 검사 122개와 확장 테스트 21개를 통과했고 통합 빌드, ZIP 압축 해제, 임시 서명 검증, 개발 Mac의 네 서비스 조회를 확인했습니다. macOS 13 및 모든 지원 기기에서의 실제 설치·실행 검증은 남아 있습니다.

앱 UI는 한국어입니다. Claude·Codex는 각 로컬 로그인 정보가, Gemini는 Chrome 확장 수동 설치가, Antigravity는 `agy` CLI가 필요합니다. 서비스 제공자 변경으로 연결이 중단될 수 있습니다. 자동 업데이트는 없습니다.

## English

See remaining Claude, Codex, Gemini web and Antigravity quota in your Mac menu bar.

**Download `AIUsageBar-1.1.1-universal.zip`.**

One file supports Apple Silicon and Intel, built for macOS 13+. The `Source code` assets are for developers, not the runnable app.

### Install

1. Extract the ZIP and move `AIUsageBar.app` to Applications.
2. Open it, then find **설정… → 표시 항목** (Settings → Visible items) in its menu bar menu.
3. Enable your services and follow the [English connection guide](https://github.com/hong-minji/ai-usage-bar/blob/main/README.en.md). The ZIP also includes `START-HERE.txt`.

**First launch:** No Apple Developer ID signing or notarization yet. If you trust the source, try opening the app, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's official guidance](https://support.apple.com/en-us/102445).

### Changes

- Registers Chrome against the installed app's current location; reconnecting repairs the host path after moving the app.
- Copies the Gemini extension folder path and improves setup instructions.
- Sets usage cache file permissions to owner-only.
- Includes a universal app, bilingual installation guide, MIT license and SHA-256 checksum.
- Adds Korean and English READMEs and a GitHub Actions build/check workflow.

### Verification and limitations

Passed 122 Swift checks, 21 extension tests, universal compilation, ZIP extraction and ad-hoc signature verification. All four providers were checked on the development Mac. Installation and execution on macOS 13 and every supported Mac model remain unverified.

The app UI is Korean. Claude and Codex require their local logins; Gemini requires manually loading a Chrome extension; Antigravity requires the `agy` CLI. Provider changes can interrupt integrations. Updates are manual.

## File integrity / 파일 무결성

Download the ZIP and `.sha256` into the same folder / 두 파일을 같은 폴더에 저장:

```sh
shasum -a 256 -c AIUsageBar-1.1.1-universal.zip.sha256
```
